# ギターコード学習サイト 設計書

- 作成日: 2026-10-11
- ステータス: レビュー待ち

## 目的

ギターのコードの形（ダイアグラム）を見て、各弦で鳴っている音がわかるようになるための学習サイト。
初心者から中級者まで対象とし、レベルが上がるごとに「必ず覚えるべきコード」から「覚えておくとよい形」へ広がっていく。

## 成功条件

- 各レベルの学習画面で、コードの押さえ方と各弦の音名・構成音が確認できる
- 各レベルで「形 → 名前」の4択クイズに挑戦でき、結果が記録される
- フロントエンドのみで完結し、サーバーを必要としない

## 決定事項

| 項目 | 内容 |
|---|---|
| 技術構成 | Vite + React + TypeScript |
| 音名表記 | C D E（英語表記）。基本は♯表記、B♭ のみ表示名を♭にする |
| クイズ形式 | 形 → 名前（4択）のみ |
| レベル移動 | 自由に選べる。レベルごとに最高正答率とクリア状況を記録する |
| 押さえ方 | 1コードにつき代表的な押さえ方を1つ |
| ルーティング | ハッシュルーティング（`#/level/1/quiz` など） |
| デプロイ | 今回は範囲外（リポジトリは private のまま） |

## レベル構成

| Lv | テーマ | コード |
|---|---|---|
| 1 | 必須コード | C, G, D, A, E, Am, Em, Dm, B（2フレットのバレー）, F（1フレットのフルバレー） |
| 2 | オープンの7th | A7, D7, E7, G7, C7, B7, Am7, Em7, Dm7 |
| 3 | バレーコード（基本） | Bm, B♭, F#m, Cm, Gm |
| 4 | バレーの7th系・sus | Fmaj7, Cmaj7, Bm7, F#m7, Asus4, Dsus4, Esus4, Asus2, Dsus2 |
| 5 | テンション・応用 | Cadd9, C6, Bdim, Caug, Bm7♭5, E9 |

## 画面構成

1. **ホーム**（`#/`）
   - Lv1〜5 のカードを並べる
   - 各カードに最高正答率と「クリア済み」バッジを出す（最高正答率 80% 以上でクリア）
   - 各カードから「学習」と「クイズ」へ進める
2. **学習画面**（`#/level/:n/study`）
   - レベル内のコードを一覧で表示する
   - ダイアグラムの各弦の下に音名を出す。ミュートは ×、開放弦は ○
   - 構成音（例: C = C・E・G）とルート音を表示する
3. **クイズ画面**（`#/level/:n/quiz`）
   - 音名を隠したダイアグラムを見せ、4択でコード名を選ぶ。1回10問
   - 回答するとすぐ正誤を出し、音名つきのダイアグラムを見せる
   - 「次へ」で次の問題に進む
4. **結果画面**（`#/level/:n/result`）
   - 正答率と、間違えたコードの一覧を表示する
   - 「もう一度」「学習に戻る」ボタン
   - 結果画面を直接開いた場合（クイズ結果がない場合）は、そのレベルのクイズ画面にリダイレクトする

存在しないレベルやパスを開いた場合はホームにリダイレクトする。

## データモデル

```ts
type Level = 1 | 2 | 3 | 4 | 5;

type Chord = {
  id: string;                    // 一意キー。例: "C", "Am", "F#m7", "Bb"
  name: string;                  // 表示名。例: "B♭"
  level: Level;
  frets: (number | null)[];      // 6弦→1弦の順、長さ6。null=ミュート, 0=開放
  fingers?: (number | null)[];   // 指番号（1〜4）。任意
  barre?: { fret: number; fromString: number; toString: number }; // 弦番号は 6〜1
  baseFret?: number;             // ダイアグラムの表示開始フレット。省略時は 1
};
```

## ロジック

### 音名の計算（`lib/notes.ts`）

- 音名は手書きせず、開放弦（6弦→1弦: E A D G B E）にフレット数を足して求める
- 12音（C, C#, D, D#, E, F, F#, G, G#, A, A#, B）の配列で表現する
- 構成音は、鳴っている音から重複を除いたもの。ルート音は最も低い弦で鳴る音とする
- 主な関数:
  - `stringNotes(chord): (Note | null)[]` 各弦の音（ミュートは null）
  - `chordTones(chord): Note[]` 構成音（重複なし、ルートから並べる）
  - `rootNote(chord): Note`

### クイズの出題（`lib/quiz.ts`）

- レベル内のコードからランダムに10問出す。コードが10個以上あれば重複させない。10個未満なら、全コードを一巡してから重複を許して補う
- 不正解の選択肢3つには、同じレベルの別コードを使う。足りない場合は他のレベルから補う
- 選択肢は正解1つ＋不正解3つ、重複なしで並び順はシャッフルする
- 乱数は引数で注入できるようにし、テストで結果を固定できるようにする

### 記録の保存（`lib/progress.ts`）

- localStorage のキー `code-master:progress` に `{ [level]: { bestScore: number; cleared: boolean } }` を保存する
- `bestScore` は 0〜100 の正答率（%）。前回より高いときだけ更新する
- 読み書きは try/catch で囲み、失敗したり不正な値だったりしても記録なしとして動く

## ディレクトリ構成

```
src/
  data/chords.ts                 # 全レベルのコード定義
  lib/notes.ts                   # 音名・構成音の計算
  lib/quiz.ts                    # 出題・選択肢の生成
  lib/progress.ts                # localStorage の読み書き
  components/ChordDiagram.tsx    # SVG ダイアグラム（showNotes で音名の表示を切り替える）
  pages/Home.tsx
  pages/Study.tsx
  pages/Quiz.tsx
  pages/Result.tsx
  App.tsx                        # ハッシュルーティング
```

- ダイアグラムはライブラリを使わず SVG で自前描画する
- `ChordDiagram` は学習・クイズ・結果画面で共通して使う

## テスト

- Vitest で `lib/` の純粋関数をテストする
  - 音名の計算: C（`[null, 3, 2, 0, 1, 0]`）→ `[null, C, E, G, C, E]`
  - 構成音・ルート音の計算
  - 選択肢: 正解がちょうど1つ含まれる、4つとも違う、同じレベルを優先する
  - 出題数が10で、10個以上のレベルでは重複しない
  - 記録: 最高値だけが更新される、壊れた値や localStorage 例外でも落ちない
- 全コードデータの整合性テスト
  - `frets` が長さ6
  - `id` が一意
  - 計算した構成音が、コード名から期待される構成音（ルート＋コードタイプの音程）と一致する
- UI は手動で確認する（UI の自動テストは今回入れない）
